# Question bank

`database.json`, `database.js`, and `vocabulary.json` are not in this public site.

They live in the private data repository under `shared/data/`. The hosted page loads `shared/data/database.json` through the Apps Script proxy after a known username signs in. A file left in this folder is only a local fallback and must not be committed.

See `../apps-script/README.md` and `../scripts/stage_shared_assets.py`.
